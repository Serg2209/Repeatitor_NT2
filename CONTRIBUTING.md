# Правила наповнення репозиторію (Contributing Guidelines)

Цей документ описує, **куди, як і за якими правилами** додавати матеріали в `Repeatitor_NT2`.

---

## 1. Куди класти новий матеріал

| Тип матеріалу | Папка |
|---|---|
| Вхідний / вихідний тест | `voor-leerlingen/diagnostiek/intake-test/` або `exit-test/` |
| Комплексна вправа (кілька навичок разом) | `voor-leerlingen/oefeningen/` |
| Граматичне «гніздо» (тема, всі сценарії, без рівня) | `voor-leerlingen/grammatica/<тема>/` |
| Лексичний блок (за рівнем) | `voor-leerlingen/lexicon/<рівень>/` |
| Текст для читання (за рівнем) | `voor-leerlingen/leesteksten/<рівень>/` |
| Аудіовправа | `voor-leerlingen/luisteren/` |
| Письмова вправа | `voor-leerlingen/schrijven/` |
| Диктант (за рівнем) | `voor-leerlingen/dictee/<рівень>/` |
| Культура, історія, легенди, фламандська vs нідерландська | `voor-leerlingen/verdieping/taal-en-cultuur/` |
| Мовні казуси, винятки з правил, професійні кейси | `voor-leerlingen/verdieping/taalcasussen/` |
| Поради із запам'ятовування, мнемотехніка | `voor-leerlingen/verdieping/leerstrategieen/` |
| Матеріали з TikTok / соцмереж | `voor-leerlingen/verdieping/social-media/` |
| План заняття | `voor-leerkrachten/lesplannen/` |
| Ключ до тесту / критерії оцінювання | `voor-leerkrachten/antwoordsleutels/` |
| Шаблон навчального профілю | `voor-leerkrachten/profielsjablonen/` |
| Дидактичний коментар | `voor-leerkrachten/didactische-notities/` |
| Інтерактивний тренажер/квіз, без прив'язки до рівня | `trainers/algemeen/<тема>/` |
| Корисне зовнішнє джерело (словник, сайт, подкаст) | `bronnen/<файл>.md` |
| Методологія, теорія, не прив'язана до рівня | `docs/` |
| Код застосунку (Нейропрофіль тощо) | корінь репозиторію — `index.html`, `main.jsx`, `package.json`, `vite.config.js`, `NT2_Neuroprofil.jsx` (не переносити в підпапку без узгодження налаштувань Vite) |

Якщо матеріал не підходить під жодну категорію — не створюйте нову папку на свій розсуд; зафіксуйте це як питання (Issue) і вирішіть структуру окремо, щоб дерево не розповзалося хаотично.

---

## 2. Іменування файлів

Формат: `<рівень>_<тема>_<тип>.ext`

Приклади:
- `B1_woordorde_oefening.docx`
- `A2_lidwoorden_quiz.html`
- `C1_zakelijke_communicatie_leesoefening.pdf`

Для `grammatica/` і `trainers/algemeen/` (без рівня) — назва теми латиницею через дефіс, без скорочень:
- ✅ `voegwoorden-tijd-oorzaak`, `modale-werkwoorden`, `de-en-het`

Для тренажерів під конкретний профіль — за рівнем/віком, **не за іменем учня**:
- ✅ `B1_teen_woordvorming`
- ❌ `Masha_woordvorming`

---

## 3. Приватність і персональні дані

Репозиторій публічний. Тому:

- **Заборонено**: реальні імена, прізвища, назви шкіл, вік, фото чи будь-які ідентифікуючі деталі конкретних учнів у назвах файлів, вмісті чи метаданих.
- Матеріали, розроблені під конкретного учня, перед додаванням у репозиторій **знеособлюються** — залишається тільки рівень, вік-група та навчальний профіль (напр. «підліток, B1, труднощі з інверсією»).
- Відповідність «файл → конкретний учень» ведеться окремо, поза публічним репозиторієм.
- Особливу увагу — матеріалам, пов'язаним із неповнолітніми: жодних деталей, що дозволяють ідентифікацію.

---

## 4. Мінімальна структура файлу матеріалу

Кожен матеріал (тест, вправа, тренажер, текст) на початку має містити короткий блок:

```
Рівень:
Тема:
Аудиторія (учень / викладач):
Орієнтовна тривалість:
```

Для матеріалів `grammatica/` і `verdieping/`, де рівень не застосовується як структура папки, поле `Рівень:` все одно заповнюється — так студент орієнтується у складності всередині безрівневої теми.

---

## 5. README у підпапках

`voor-leerlingen/README.md` містить навігацію по всіх розділах для учнів і оновлюється при появі нової категорії. За тим самим принципом варто вести `voor-leerkrachten/README.md`, коли розділів стане більше одного-двох.

---

## 6. Git-workflow

- Оновлення `voor-leerlingen/`, `voor-leerkrachten/`, `trainers/`, `bronnen/`, `docs/` — можна напряму в `main` (це бібліотека контенту, не код із ризиком регресій).
- Зміни в коді застосунку (`index.html`, `main.jsx`, `NT2_Neuroprofil.jsx`, `vite.config.js`) — через окрему гілку та Pull Request.
- Повідомлення комітів — коротко і по суті, українською, напр.:
  - `Створено папку grammatica/modale-werkwoorden`
  - `Додано вхідний тест A0-B1`
  - `Оновлено ключі до тестів для граматичних гнізд`
