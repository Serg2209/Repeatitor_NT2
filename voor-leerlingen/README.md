# Voor leerlingen — навігація матеріалів

Короткий огляд розділів, щоб самостійно обрати матеріал під свій рівень, мету та навантаження.

## Діагностика

- **`diagnostiek/intake-test/`** — вхідний тест, визначення рівня (A0–C2) перед початком занять
- **`diagnostiek/exit-test/`** — вихідний тест, перевірка прогресу після модуля

## Вправи за навичками

- **`oefeningen/`** — комплексні вправи, що поєднують кілька навичок в одному завданні (на відміну від розділів нижче, які відпрацьовують одну навичку окремо)
- **`grammatica/`** — граматичні «гнізда»: тема в усіх сценаріях вживання, без прив'язки до рівня (напр. `dat/omdat/nadat/zodat/opdat/voordat`, модальні конструкції). Складність оберіть самі за описом у заголовку файлу
- **`lexicon/`** — лексичні блоки за рівнем (A1 → C1)
- **`leesteksten/`** — тексти для читання за рівнем (A1 → C1)
- **`luisteren/`** — аудіовправи
- **`schrijven/`** — письмові вправи (formeel / informeel)
- **`dictee/`** — диктанти за рівнем (A1 → C1)

## Поглиблення (verdieping)

Матеріали поза обов'язковим треком — для тих, хто хоче зануритись глибше:

- **`verdieping/taal-en-cultuur/`** — історія Бельгії, місцеві міфи та легенди, особливості фламандської порівняно з нідерландською
- **`verdieping/taalcasussen/`** — винятки з правил, нові мовні правила, професійні кейси вживання мови
- **`verdieping/leerstrategieen/`** — поради з мнемотехніки та запам'ятовування нових слів, Goesting in taal
- **`verdieping/social-media/`** — матеріали з TikTok та інших соцмереж

## Як користуватися

Відкрийте потрібний файл прямо в браузері на телефоні, планшеті чи комп'ютері — нічого встановлювати не потрібно. Кожен файл вправи/тексту має короткий заголовок (`Рівень:`, `Тема:`) — орієнтуйтесь по ньому, обираючи матеріал під свій рівень.
