# Repeatitor_NT2
Repeatitor_NT2 — це інструмент для викладачів та тьюторів нідерландської NT2, який автоматизує створення навчальних матеріалів: карток, вправ, текстів, презентацій та мікро‑курсів. Проєкт допомагає швидко генерувати структурований контент для уроків, самостійної роботи та тренувальних платформ (Quizlet, Canva, Slides).
