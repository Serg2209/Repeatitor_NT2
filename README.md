# Repeatitor_NT2

## Що це

**Repeatitor_NT2** — збірник готових навчальних матеріалів з нідерландської як другої мови (NT2).

Матеріали розраховані на **дві аудиторії**:

- **Учні та студенти** — для самостійної діагностики, повторення та тренування
- **Викладачі та репетитори** — для використання на заняттях, підготовки тестів та побудови індивідуальних траєкторій

Усе розроблено для україномовних студентів у бельгійському та нідерландському контексті.

---

## Для учнів

Повна навігація по матеріалах — у [`voor-leerlingen/README.md`](voor-leerlingen/README.md).

Коротко:

- **Діагностика** — вхідний та вихідний тест (A0–C2)
- **Вправи за навичками** — граматика, лексика, читання, аудіювання, письмо, диктанти
- **Поглиблення (verdieping)** — культура, мовні казуси, стратегії запам'ятовування, матеріали з соцмереж

**Як користуватися:** відкрийте потрібний файл у браузері на телефоні, планшеті чи комп'ютері. Нічого встановлювати не потрібно.

---

## Для викладачів

- **`voor-leerkrachten/lesplannen/`** — плани занять, структуровані за темами та рівнями
- **`voor-leerkrachten/antwoordsleutels/`** — ключі до тестів, критерії оцінювання, типові помилки
- **`voor-leerkrachten/profielsjablonen/`** — шаблони навчальних профілів
- **`voor-leerkrachten/didactische-notities/`** — дидактичні коментарі, типові труднощі україномовних

### Як інтегрувати

1. Надішліть учневі посилання на вхідний тест *до* першого заняття — отримаєте готову картину рівня
2. Використовуйте тренажери на уроці (проєкція) або як домашнє завдання
3. Проводьте вихідне тестування кожні 8–10 занять — фіксуйте динаміку

### Принципи іменування

- Назва теми/файлу: латиниця, малі літери, слова через дефіс (напр. `voegwoorden-tijd-oorzaak`, `B1_woordorde_oefening.docx`)
- Тренажери й матеріали іменуються **за рівнем/темою**, не за іменем конкретного учня — репозиторій публічний, персональні дані учнів у назвах і вмісті не використовуються
- Рівень — у структурі папки там, де матеріал кумулятивний (`lexicon`, `leesteksten`, `dictee`); тема без рівня — там, де матеріал сценарний (`grammatica`, `trainers/algemeen`)

Детальні правила наповнення — у [`CONTRIBUTING.md`](CONTRIBUTING.md).
