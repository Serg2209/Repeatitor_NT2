# Repeatitor_NT2

## Що це

**Repeatitor_NT2** — збірник готових навчальних матеріалів з нідерландської як другої мови (NT2).

Матеріали розраховані на **дві аудиторії**:

- **Учні та студенти** — для самостійної діагностики, повторення та тренування
- **Викладачі та репетитори** — для використання на заняттях, підготовки тестів та побудови індивідуальних траєкторій

Усе розроблено для україномовних студентів у бельгійському та нідерландському контексті.

---

## Для учнів

### Діагностика

- **Вхідний тест** — дізнайтеся свій рівень (А0–С2) перед початком занять
- **Вихідний тест** — перевірте прогрес після модуля
- **Мій навчальний профіль** — побачте свої сильні сторінки та зони росту

### Тренажери та вправи

- Граматичні «гнізда» — відпрацюйте кожну тему в усіх сценаріях використання
- Лексичні блоки за рівнями (А1 → С2)
- Аудіовправи (luisteren)
- Письмові вправи (formeel / informeel schrijven)

**Як користуватися:** відкрийте потрібний файл у браузері на телефоні, планшеті чи комп'ютері. Нічого встановлювати не потрібно.

---

## Для викладачів

### Методичні матеріали

- **Плани занять** — структуровані за темами та рівнями
- **Ключі до тестів** — критерії оцінювання, типові помилки
- **Шаблони навчальних профілів** — для заповнення під конкретного учня
- **Дидактичні коментарі** — пояснення до вправ, типові труднощі україномовних

### Як інтегрувати

1. Надішліть учневі посилання на вхідний тест *до* першого заняття — отримаєте готову картину рівня
2. Використовуйте тренажери на уроці (проєкція) або як домашнє завдання
3. Проводьте вихідне тестування кожні 8–10 занять — фіксуйте динаміку

### Принципи іменування

- Файли: `<рівень>_<тема>_<тип>.ext`, напр. `B1_woordorde_oefening.docx`
- Тренажери іменуються **за рівнем/віковим профілем**, а не за іменем конкретного учня (напр. `B1_teen_woordvorming`, не `Masha_woordvorming`) — репозиторій публічний, персональні дані учнів у назвах та вмісті файлів не використовуються
- У кожній ключовій папці (`content/students/`, `content/teachers/`) бажано мати короткий `README.md` з описом вмісту
